AgriVision — Real-time pesticide residue detection

AgriVision is a cross-platform solution (mobile and desktop) that detects pesticide residues on fruits using computer vision and machine learning. The system combines high-quality image preprocessing with a lightweight, optimized model to provide quick, on-device inference using TensorFlow Lite. A Flutter front-end enables a responsive user experience for field technicians and consumers, while a Python/OpenCV backend handles image enhancement and dataset curation.

Key features include real-time on-device inference, adaptive preprocessing pipelines to handle varied lighting conditions, a model trained with augmented datasets to improve robustness, and an intuitive mobile UI for capturing and reviewing results. AgriVision is designed to be efficient, privacy-preserving, and deployable in low-connectivity environments.

Python TensorFlow Lite Flutter OpenCV

Fake News Detection using LLM

This project applies transformer-based models and classical NLP techniques to detect misleading or fabricated news content. The system combines TF-IDF features and careful preprocessing with transformer embeddings to capture both lexical patterns and contextual semantics. The pipeline includes data collection, deduplication, label quality checks, and training with a focus on calibration to reduce false positives.

The detection stack leverages established transformer encoders fine-tuned for classification, alongside feature-based models for explainability. Outputs include a probability score, a rationale produced from attention highlights, and suggestions for manual review when confidence is low.

Python NLP Transformers TF-IDF

Role: Implemented preprocessing, feature engineering, and fine-tuned transformer models; emphasized explainability and evaluation metrics tailored to misinformation detection.
